IOT projects
============

.. note:: **TL;DR**
   - Firmware and IoT project articles based on **Espressif ESP32 and ESP32-S3** — covering **RTSP video streaming bridges, remote controller firmware with state machines, MQTT/BLE/Wi-Fi connectivity, and CI/CD with Gerrit and Jenkins**.
   - Built on **ESP-IDF, FreeRTOS, NimBLE, and MQTT5** with automated testing via Unity, Valgrind, and LCOV.
