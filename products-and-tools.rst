=======================
Amarula Products & Tools
=======================

.. note:: **TL;DR**
   - Overview of Amarula Solutions' **open source products and developer tools** — including the **ChatGPT Gerrit Code Review plugin**, **CuteKeyboard** (Qt virtual keyboard), **Flutekeyboard**, **Jelliphy** (AI web framework), **DynDesign** (Python dynamic decoration), **meta-mend** (Yocto security), **libcppconnman**, and the **git-collect Jenkins plugin**.

AI-Powered Tools
================

- **ChatGPT Gerrit Plugin** — AI-assisted code review in Gerrit with voting, comment resolution, and on-demand context fetching.
  See `opensource/products/chatgpt-gerrit <opensource/products/chatgpt-gerrit.html>`_.

- **Jelliphy** — No-code browser-based AI framework for interactive web application development using ChatGPT.
  See `articles/ai/jelliphy <articles/ai/jelliphy.html>`_.

Embedded UI Tools
=================

- **CuteKeyboard** — Open-source Qt virtual keyboard, now in Yocto's meta-qt layer.
  See `opensource/products/cutekeyboard <opensource/products/cutekeyboard.html>`_.

- **Flutekeyboard** — Flutter-based virtual keyboard for embedded displays.
  See `opensource/products/flutekeyboard <opensource/products/flutekeyboard.html>`_.

Build & Security Tools
======================

- **meta-mend** — Yocto layer for Mend SCA vulnerability analysis.
  See `opensource/products/meta-mend <opensource/products/meta-mend.html>`_.

- **git-collect-plugin** — Jenkins plugin for collecting Git repository statistics.
  See `opensource/products/git-collect-plugin <opensource/products/git-collect-plugin.html>`_.

Python & C++ Libraries
======================

- **DynDesign** — Python library for dynamic class decoration, merging, and builder patterns.
  See `opensource/products/dyndesign/index <opensource/products/dyndesign/index.html>`_.

- **libcppconnman** — C++ wrapper for ConnMan network manager.
  See `opensource/products/libcppconnman <opensource/products/libcppconnman.html>`_.
