Vyasa RK3288
############

.. note:: **TL;DR**
   - **Vyasa RK3288** is a single-board computer based on the **Rockchip RK3288 SoC** (quad-core ARM Cortex-A17) — supported by Amarula Solutions with **mainline U-Boot and Linux kernel** integration, Buildroot/Yocto BSP, and upstream-first methodology.
   - Features include HDMI, USB, Gigabit Ethernet, eMMC, and LVDS/MIPI DSI display interfaces.

For detailed mainline BSP build instructions, see the `Rockchip RK3288 section <https://wiki.amarulasolutions.com/bsp/rockchip/rk3288/index.html>`_.
